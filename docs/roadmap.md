# RADIX Roadmap

This document outlines the current direction of the RADIX skill and ROOT DATA TOKEN ($RADIX).

RADIX is an early-stage project exploring better data and community intelligence for AI agents operating on Robinhood Chain.

---

## Phase 1 — Foundation (Current)

- [x] Public repository
- [x] Core `SKILL.md` structure
- [x] Reference files for consistent output
- [x] Basic documentation & examples
- [x] MIT License

**Goal:** Establish a clean, usable skill that can be installed and tested by the community.

---

## Phase 2 — Core Radar Functionality

- [ ] Reliable new launch detection on Robinhood Chain
- [ ] Top volume / activity summaries
- [ ] Clean and consistent digest format
- [ ] Basic token status checks
- [ ] Improved handling of sparse data periods

**Goal:** Make the radar genuinely useful in daily use.

---

## Phase 3 — Usability & Distribution

- [ ] Better trigger coverage
- [ ] Optional scheduled digests
- [ ] Clearer examples and usage guides
- [ ] Community feedback integration
- [ ] Potential submission to Bankr skills catalog

**Goal:** Increase adoption and real-world usage among Bankr agents and builders.

---

## Phase 4 — Deeper Intelligence (Future)

- [ ] Stronger holder / liquidity signals
- [ ] Better distinction between memecoins and tokenized stocks
- [ ] Historical context where available
- [ ] More advanced filtering options
- [ ] Exploration of additional data sources (if reliable)

**Goal:** Move from basic radar toward higher-signal community intelligence.

---

## Token Alignment

**ROOT DATA TOKEN ($RADIX)** is intended to align incentives around the skill and future data-related tools.

Token utility and distribution details will be developed carefully and shared transparently as the project matures.

---

## Principles

- Prefer clarity over noise
- Prefer useful data over hype
- Build in public
- Iterate based on real usage
- Keep agents and humans in mind
