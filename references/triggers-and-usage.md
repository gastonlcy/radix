# RADIX Triggers & Usage

## Strong Triggers (always activate)

- “RADIX radar”
- “Robinhood Chain radar”
- “RH radar”
- “What’s happening on Robinhood Chain”
- “New launches on Robinhood Chain”
- “Top volume on Robinhood Chain”
- “Robinhood Chain market overview”
- “Community digest Robinhood”
- “Give me a RADIX update”

## Medium Triggers (activate when context fits)

- Questions about activity / trending tokens specifically on Robinhood Chain
- Requests for discovery or intelligence on that chain
- Comparisons that include Robinhood Chain launches or volume

## Example User Requests → Expected Behavior

| User says | You should |
|---------|------------|
| RADIX radar | Full digest format |
| Top volume on Robinhood right now | Short volume snapshot |
| Any new tokens on RH chain today? | Focus on recent launches section |
| Check $TICKER on Robinhood | Single token check format |
| Quiet day on Robinhood? | Honest quiet market response |

## Explicit Call
