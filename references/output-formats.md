# RADIX Output Formats

Use these templates so responses stay consistent and scannable.

## Full Radar Digest (recommended default)

```
🌱 RADIX Radar — Robinhood Chain
Updated: [timestamp or "latest available"]

### New / Recent Launches
- $TICKER — short note (age, notable signal if any)
- $TICKER — ...
- ...

### Top by Volume / Activity
1. $TICKER — key metric or observation
2. $TICKER — ...
3. $TICKER — ...

### Notable Mentions
- Any standout movers, high activity, or interesting patterns

### Quick Take
1–3 neutral sentences summarizing current activity level and any clear patterns.
```

## Short Volume Snapshot

```
🌱 RADIX — Top Activity (Robinhood Chain)

1. $TICKER
2. $TICKER
3. $TICKER
4. $TICKER
5. $TICKER

Source: latest available Bankr data

```
🌱 RADIX — $TICKER (Robinhood Chain)

• Price / status: ...
• Notable signals: ...

```

## Quiet Market Response

When data is sparse:

```
🌱 RADIX Radar — Robinhood Chain

Current data shows limited new launches / low reported volume in the latest window.

No strong standout activity detected at this time.
```
